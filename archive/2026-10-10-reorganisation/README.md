# Path map of the 2026-10-10 reorganisation

On 2026-10-10 `scripts/` (a flat directory of 124 files) was grouped by role
into `data/`, `train/`, `measure/`, `studies/<study>/` and `pods/`; see
`scripts/README.md`. Nothing was edited beyond the paths that point at other
files.

`scripts.tsv` maps each old path to its new one, one file per line. Use it to
follow a path recorded before the move: in a results table's header, a pod log
on the volume, a commit message or a memory note.
