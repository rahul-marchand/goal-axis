Coding mechanisms here: requential. For requential runs SDL is the total code (cumulative
teacher-student KL plus per-call overhead) over the coded samples, n is the number of samples, and
L(0), L(n), EDL and ceiling read the student's curve on T: not comparable with prequential rows.

Retargeting cost of route models: block-prequential code, doubling blocks, refit from the base
before every block, early-stopped on V. Bits per route; SDL = MDL since L* = 0 (perfect mazes,
tied levels dropped). flip = share of D whose expert choice differs from the base rate's.
ceiling = n L(0), never leaving the base. SDL-null = SDL minus the agent's null arm (tau 10)
at the same replicate settings, compared per token within each block (routes shorten as tau
falls); raw = the same per route. min = wall-clock minutes for the run.
