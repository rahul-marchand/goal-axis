# E6: why the written axis is slow and breaks down below parity

Three DRC g1 bases (s1234, s9012, s3456e), the o1 axis, the held-out test split.
Each condition is 16,384 episodes; conditions are paired across rows, with a
bootstrap over levels. τ is the pooled crossing.

Reached for the axis at dv 2.5 on the other bases: s9012 28.5%, s3456e 28.1%.

- **The log law holds for colour-1 brightness up to about ×3.** τ = a − b·ln g with
  b = 6.2 / 6.3 / 5.5 (rms 0.15 / 0.51 / 0.19). Inside the window, k = 1.74 / 1.63 / 1.30.
- **The axis leaves its log-law prediction** by more than 0.5 steps at dv ≈ 1.0–1.5.
- **Reached first drops below 95% at dv 1.5** on all three bases.
- s9012's reported departure at dv 0 is a fit artefact: its brightness curve misses the
  base by 0.9 steps.

## Parts of the axis, and random writes

Values are for s1234; ranges cover all three bases.

| Part | Passes τ = 0 at | Reached there | Further |
|---|---|---|---|
| gain part, in weights | never (τ 4.4 at 2.5) | 100% | identical to brightness to 2 dp (plumbing check) |
| input conv alone | dv ≈ 1.9 (2.3 / 1.7) | ≥ 97.6% | τ −1.8 at 2.5 |
| input conv, rescaled | dv ≈ 0.8 (1.1 / 0.9) | ≥ 99% | −1.5 / 0.5 / −0.6 at dv 1.0; breaks down only near τ −3 to −5 |
| axis minus gain part | ≈ axis | ≈ axis | reproduces the full axis's flattening and breakdown almost exactly |
| isotropic random, same norm | — | — | reached at dv 2.5: 18–81% / 79–95% / 33–77% (draw spread); \|Δτ\| mostly < 2 |
| per-module random | — | — | reached ≤ 23% from dv 0.3 |

About the per-module random writes: the axis puts its length into small modules
(the input conv among them), and a random direction of that length there
destroys the network. So the axis's weights inside those modules are highly
structured, not noise.

## Verdict

1. **It is slow because its gain saturates, not because it stops being a gain.** At
   every dose up to 2.5, a pure brightness reproduces the axis's threshold to within
   about 0.15 steps while still reaching 98.7–100% of objectives. That holds for
   colour 1 alone, colour 0 alone, or both planes. What saturates is the mapping from
   dose to equivalent gain: at dv 2.5 the matched gain is 3.4 / 2.9 / 2.8, against
   5.4 / 5.1 / 4.2 if it stayed linear.
2. **The saturation comes from outside the input conv, and so does the breakdown.**
   - The input-conv slice by itself keeps moving τ almost linearly and crosses zero
     cleanly.
   - The rest of the axis stops adding threshold shift at high dose, and it costs the
     agent competence at about the rate of a random write of the same norm.
     Isotropic random writes lose competence without moving τ; the axis loses it
     somewhat earlier on s9012 and s3456e.
   - Consistent with this, "axis minus gain part" behaves like the full axis.
3. **Nothing here needs a separate value circuit.** A gain written into the input conv
   reaches τ < 0 with the agent intact. The fitted axis fails below parity because it
   is a first-order, noisy direction: its non-input part saturates and then damages
   the network when extrapolated 5× past the window.

## Caveats

- **Brightness saturates too.** At ×4–5 its τ flattens (s1234 ×5: −2.0 vs −3.1
  predicted; s9012 ×5: −1.1 vs −3.5) and reached falls to 71–91%. So the "1+k·dv"
  prediction overstates how far a real gain could go.
- **τ counts only episodes that reached an objective.** When reached is low, some of
  the flattening may come from which episodes are left.
- **Scope:** o1 only; the per-module random writes used 2 draws.
