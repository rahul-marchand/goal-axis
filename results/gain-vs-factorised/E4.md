## Edit families
- **reach** = slope of held-out τ on the written dose; 1 means the edit fully does what it was trained to do.
- **cos Ju,Jv** = function-space cosine with the fitted axis v.
- **seed cos** = agreement between the two search seeds.

| family | reach (s1234 / s9012 / s3456e) | ‖u‖/‖v‖ | cos Ju,Jv | seed cos |
|---|---|---|---|---|
| readout (dense + heads) | 0.15 / 0.07 / 0.21 | 3.9–5.5 | +0.06 / +0.08 / +0.11 | 0.01–0.49 |
| late (cell 2 + dense + heads) | 0.79 / 0.76 / 0.65 | 3.9–5.6 | +0.63 / +0.77 / +0.49 | 0.30–0.64 |
| input conv only | 0.89 / 0.79 / 0.71 | **0.83–1.03** | **+0.94 / +0.96 / +0.83** | **0.98–0.99** |
| unrestricted | 0.93 / 0.92 / 0.88 | 4.0–5.5 (49–71% of it in dense) | +0.72 / +0.81 / +0.60 | 0.21–0.45 |

- **Readout cannot carry value.** Even at 4–5× the axis's length it gets 7–21% of the target shift, in a direction unrelated to v.
- **Input conv only is the cheapest and the most determined edit.** It reaches 71–89% at below the axis's own total norm, which is about 2× the axis's input-conv slice. Both seeds find the same edit (seed cos 0.98–0.99), and it moves the policy the way v does (cos 0.83–0.96).
- **Late and unrestricted edits need about 5× the norm** and are less unique. The unrestricted search's norm goes mostly into dense (Adam spreads step noise over the big matrix), so its size is not a minimum.

## Side effects at ±4 steps
Across the edited nets, both objectives are still reached and usually by an optimal route. The one signature that separates the families is **P opt**: how often the agent takes an optimal route when it goes for the poor, colour-1 objective. Raising τ by 4 steps:

| base | v | input | late | readout (τ barely moves) |
|---|---|---|---|---|
| s1234 | 76 → 65% | 66% | 76% | 79% |
| s9012 | 75 → 65% | 69% | 79% | 77% |
| s3456e | 71 → 59% | 63% | 73% | 70% |

The fitted axis shares this damage with the input-conv edit, and the late edit does not have it. Dimming colour 1 makes the agent route to colour 1 worse, which is the gain signature. **The axis SGD found carries input-gain collateral, not late-edit collateral.**

- Navigation is not hurt: single-objective R/P ok stay at 98–100% for frozen arms.
- With the encoder frozen, SGD reproduces nearly the same *function* change through the ConvLSTM cells, using different weights.

## Verdict
**Leans H1: value has to enter through the planning computation.** It cannot be bolted onto the readout.
- **Cheapest:** changing how strongly colour is seen at the input. That edit is unique, matches the axis in function space, and matches its route-optimality signature.
- **Next cheapest:** if the input is frozen, the recurrent planner (cells 0–2) can implement the same function change.
- **Unavailable:** readout alone is not a substitute.

The one H2-compatible reading left is a value variable living *inside* the cells whose effect is indistinguishable from salience (see E1).

**Caveats**
- Adam without a norm ball, so norms are not minima.
- s3456e is weaker on every measure.
- o1 axis only; DRC only.
