# E13: where in the sequence does the route model's value axis act?

the unedited model at one subset of tokens at a time. `share` is the fraction of the
weight write's threshold shift that subset carries. **Read the `all` row first** -- if it
is not near 1.00 the write is not reproducible by patching at that depth and the other
rows mean nothing.

## How to read it

- `objectives` carrying the shift: value is written into the objective's own
  representation, before any comparison.
- `sep` carrying it: value is applied at the decision token -- the factorised story.
- `other cells` carrying it: value is spread over the maze representation.
- Competence columns matter: a subset that moves tau by breaking the model
  (reached far below the base's) is not a value knob.

Caveat: three earlier steering attempts on this model were null because the linearly
decodable gap direction is not load-bearing. This patches the axis's own activation
difference instead, which is why the `all` control is the first thing to check.
